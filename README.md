## Что это такое

CryptoSim — веб-игра симулятор криптовалютной торговли.
Ты начинаешь со $100 и торгуешь на трёх независимых биржах с разными характерами рынка.
Цены обновляются в реальном времени, на рынок влияют случайные события, погода, хакеры и хайп-циклы.

---

## Быстрый старт

### Требования
- Python 3.10, 3.11 или 3.12 (рекомендуется 3.11)
- pip

### Установка и запуск

```bash
# 1. Установить зависимость
pip install flask

# 2. Перейти в папку проекта
cd cryptosim

# 3. Запустить сервер
python app.py
```

Открыть в браузере: **http://localhost:5000**

## Биржи

| Биржа | Монета | Характер | Регион | Волатильность |
|-------|--------|----------|--------|---------------|
| NovaCrypt | NVC | Стабильный | Europe | Низкая |

## Симуляция рынка

Цены формируются из нескольких слоёв:

- **Случайное блуждание** — базовый шум по нормальному распределению
- **Характер биржи** — стабильная тянется к базовой цене, волатильная усиливает тренд, хаотичная использует синус-волны
- **Погодные модификаторы** — у каждого региона своя математическая функция влияния
- **События** — 14 типов событий с разной вероятностью и силой воздействия

### Список событий
Whale Dump, Whale Buy, Exchange Hack, Institutional Buy, Regulatory Crackdown,
Partnership Announced, Flash Crash, Hype Cycle, Miner Capitulation, Network Upgrade,
Iran Water Crisis, Energy Cost Spike, Flood Season, Grid Blackout

## API

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/tick` | GET | Следующий тик симуляции + данные рынка |
| `/api/state` | GET | Кошелёк, holdings, история сделок |
| `/api/trade` | POST | Купить или продать |
| `/api/profile` | POST | Обновить имя и фото профиля |
| `/api/reset` | POST | Сбросить игру (профиль сохраняется) |

---

## Сохранение

- Прогресс **автоматически сохраняется** каждые 30 секунд в `save_data.json`
- Дополнительно сохраняется **сразу после каждой сделки**
- После перезапуска сервера — всё восстанавливается
- Профиль (имя, фото) **не сбрасывается** при reset игры

---

## Правила игры

- Стартовый капитал: **$100 USD**
- Комиссия за каждую сделку: **0.1%**
- Цены обновляются каждые **2.5 секунды**
- Цель: увеличить портфель как можно больше
